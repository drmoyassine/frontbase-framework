# WordPress pilot: current execution plan

**Updated:** 2026-10-08, after pushed main checkpoint `01b2456`. This plan supersedes older next-task and local-only/uncommitted statements in the roadmap, handoff and swarm reports. Historical verification remains dated evidence, not a fresh integrated result.

## Goal

An owner installs Frontbase, connects a database and file storage, configures an education-directory template in `/frontbase-admin`, and publishes on their domain without editing framework source. One self-host deployment is one site/application and engine/worker. USA proves real migration; a separate country deployment proves reuse.

Supabase supplies authoritative content; WordPress supplies original public URLs and gap evidence. Extra Supabase records are intentional expansion. Every original public record/path needs a reviewed destination or explicit disposition. Keep institution/program/city relationships, editorial identity and configurable storage. Missing optional covers collapse; enrichment remains a separate pass. Retain the existing admin, six framework packages, query/provider contracts, one engine and Cloud owner isolation. Primary owns design, integration and final verification; this plan does not dispatch new agents.

## Shared read path

[Native Inspector adapter](../../packages/backend/src/compat/postgrest-inspector.ts) reuses the existing selected-schema PostgREST client, credential resolution, guarded HTTPS transport and [saved-filter HTTP compiler](../../packages/backend/src/compat/saved-view-http.ts). Connection checking and Inspector discovery now share the same bounded metadata reader/JSON decoder. Metadata is per request, never a shared credential/tenant cache.

Native table discovery uses GET endpoints in the selected schema's OpenAPI document; `/rpc` paths are not tables. Column types, required/nullable columns, primary-key annotations and published foreign-key annotations come from that metadata. The adapter does not crawl other schemas or infer unavailable database information. Conventional identifier names are supported; unsupported metadata/field shapes fail closed.

Table rows, exact counts, offset pagination, validated sort and supported filter groups use direct PostgREST GET/HEAD requests. Existing Inspector filter semantics reuse the saved-filter AST/HTTP compiler, including rejecting unsupported values rather than omitting predicates. Saved-view preview, records and count routes use the same read adapter. Native datasource search uses text columns, at most 50 exposed tables and concurrency two; requests remain bounded. No SQL translation, generic SQL RPC bootstrap or runtime PostgreSQL connection is added. Standard Supabase/other datasource paths are unchanged.

Native reads are limited to 500 records per page and 8MiB responses, with guarded deadlines and a shared 15-second read phase. Row shape and exact counts are validated; invalid/oversized responses and remote provider errors are sanitized. Native transport refuses mutation methods before network dispatch. This slice enables Inspector reads; record mutation, aggregate/join queries and richer relationship editing are not claimed as native implementations. Remote records, credentials, schema/grants, translation execution and publication are not changed during acceptance.
